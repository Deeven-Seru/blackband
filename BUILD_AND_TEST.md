## Prerequisites

| Dependency | Minimum version | Notes |
|---|---|---|
| CMake | 3.20 | Build system |
| LLVM | 17 | Code generation backend |
| libcurl | any | Network module (`net::get`, `net::post`) |
| G++ or Clang++ | C++20 support | Compiler toolchain |
| Ninja *(optional)* | any | Faster builds than `make` |

### Installing on Ubuntu/Debian

```bash
sudo apt-get update
sudo apt-get install -y \
    cmake ninja-build libcurl4-openssl-dev \
    llvm-17 llvm-17-dev clang-17 libclang-17-dev lld-17 \
    pkg-config

# Make llvm-17 tools the default
sudo update-alternatives --install /usr/bin/llvm-config llvm-config \
    /usr/bin/llvm-config-17 100
sudo update-alternatives --install /usr/bin/clang++ clang++ \
    /usr/bin/clang++-17 100
```

### Installing on macOS (Homebrew)

```bash
brew install llvm cmake ninja curl

export PATH="$(brew --prefix llvm)/bin:$PATH"
export LDFLAGS="-L$(brew --prefix llvm)/lib"
export CPPFLAGS="-I$(brew --prefix llvm)/include"
```

## Building from Source

```bash
# 1. Clone the repository (if you haven't already)
git clone https://github.com/Deeven-Seru/blackband.git
cd blackband

# 2. Configure
cmake -S agentc -B agentc/build \
    -G Ninja \
    -DCMAKE_BUILD_TYPE=Release \
    -DCMAKE_CXX_COMPILER=clang++-17

# 3. Compile
cmake --build agentc/build --parallel $(nproc)
```

The compiled binary is at `agentc/build/agentc`.

### Verify the build

```bash
agentc/build/agentc --version
```

Expected output:

```
agentc 0.5.0
```

## Running Examples

AgentC source files use the `.agc` extension. Compile them with:

```bash
agentc/build/agentc agentc/examples/<program>.agc -o <output_binary>
```

### Success examples (should compile and run)

| File | What it demonstrates |
|---|---|
| `spec_conformance.agc` | Every language construct |
| `state_machine_agent.agc` | Mutable state with `~` |
| `briefing_agent.agc` | Network + LLM + file I/O |
| `compare_agentc.agc` | Simple network + AI + file write |

```bash
# Compile and run the state machine example
agentc/build/agentc agentc/examples/state_machine_agent.agc -o /tmp/state_machine
/tmp/state_machine
cat state_log.txt   # output file created by the agent
```

### Security-proof examples (should be rejected by the compiler)

These programs intentionally violate safety rules and **must not compile**:

| File | Violation | Expected error |
|---|---|---|
| `proof_immutability.agc` | Reassigns an immutable `$` binding | `E201` |
| `proof_trust.agc` | Passes `Utr<Str>` to a trusted sink | `E301` |
| `proof_cap.agc` | Uses `net::get` without the `net` capability | `E503` |
| `proof_bounds.agc` | Assigns unbounded integer to `Bnd<i32,0,120>` | `E305` |
| `proof_purity.agc` | Side-effect inside a `#!(none)` pure function | `E505` |

```bash
# This should print an error and exit non-zero
agentc/build/agentc agentc/examples/proof_immutability.agc -o /dev/null
echo "Exit code: $?"   # should be non-zero
```

## Running Tests

### Quick automated check

```bash
chmod +x verify_tests.sh
./verify_tests.sh
```

The script:
1. Checks that the `agentc` binary exists.
2. Compiles all success examples and verifies they succeed.
3. Compiles all security-proof examples and verifies they fail.
4. Runs the CMake/ctest unit-test suite.
5. Writes `test_results.json` to `/tmp/results/`.

Use `--agentc` to point to a different binary:

```bash
./verify_tests.sh --agentc /path/to/custom/agentc
```

### Unit tests only (via ctest)

```bash
cd agentc/build
ctest --output-on-failure -V
```

### Individual test executables

```bash
# All unit tests in one binary
./agentc/build/agentc_tests

# LSP tests
./agentc/build/agentc_lsp_tests
```

## Interpreting Test Results

### Console output

| Symbol | Meaning |
|---|---|
| ✅ PASS | Test behaved as expected |
| ❌ FAIL | Test did not behave as expected |

### `test_results.json`

Generated by `verify_tests.sh` at `/tmp/results/test_results.json`:

```json
{
  "timestamp": "2026-01-01T00:00:00Z",
  "compiler": "/workspace/agentc/build/agentc",
  "summary": {
    "total": 10,
    "pass": 10,
    "fail": 0
  },
  "tests": [
    { "name": "spec_conformance", "status": "PASS", "note": "" },
    { "name": "proof_immutability", "status": "PASS", "note": "correctly rejected (E201)" }
  ]
}
```

- **`summary.total`** — number of tests run.
- **`summary.pass`** — tests that behaved correctly (either compiled or rejected, as expected).
- **`summary.fail`** — tests that did not behave correctly.
- **`tests[].status`** — `"PASS"` or `"FAIL"`.
- **`tests[].note`** — human-readable reason for PASS or FAIL.

### Exit codes

| Code | Meaning |
|---|---|
| `0` | All tests passed |
| `1` | One or more tests failed |

## Using Docker

Build and test inside a fully reproducible Ubuntu 22.04 container:

```bash
# Build the image (installs all deps, compiles AgentC, runs tests)
docker build -t agentc .

# Print the JSON test report
docker run --rm agentc

# Interactive shell
docker run --rm -it agentc /bin/bash
```

## CI/CD Pipeline

Every push and pull request automatically triggers the GitHub Actions workflow
at `.github/workflows/ci.yml`. The pipeline:

1. Installs LLVM 17, CMake, libcurl, Clang++ on `ubuntu-22.04`.
2. Configures and builds the AgentC compiler.
3. Runs all unit tests via `ctest`.
4. Compiles the four success examples and verifies they succeed.
5. Compiles the five security-proof examples and verifies they fail.
6. Generates `test_results.json` and uploads it as a build artifact.

A green check mark means the compiler builds correctly and all safety
properties are proven. A red cross means at least one check failed — click on
the failed job for details.

## Troubleshooting

### `llvm-config: not found`

Ensure LLVM 17 is installed and on your `PATH`:

```bash
sudo apt-get install llvm-17 llvm-17-dev
sudo update-alternatives --install /usr/bin/llvm-config llvm-config \
    /usr/bin/llvm-config-17 100
llvm-config --version   # should print 17.x.x
```

### `find_package(LLVM REQUIRED CONFIG)` fails during CMake

CMake needs the LLVM CMake modules. Pass the path explicitly:

```bash
cmake -S agentc -B agentc/build \
    -DLLVM_DIR=$(llvm-config-17 --cmakedir)
```

### `find_package(CURL REQUIRED)` fails

Install the development package:

```bash
# Ubuntu / Debian
sudo apt-get install libcurl4-openssl-dev

# macOS
brew install curl
```

### Linker errors mentioning `-lLLVM*`

Make sure the LLVM shared/static libraries are installed:

```bash
sudo apt-get install llvm-17-dev libllvm17
```

### Security-proof example compiles without errors

This means the type-checker is not enforcing the expected rule. Check the error
code in the compiler output and compare with the rules in
`agentc/src/typechecker/rules.cpp`.

### `verify_tests.sh: agentc binary not found`

Build the compiler first:

```bash
cmake -S agentc -B agentc/build -DCMAKE_CXX_COMPILER=clang++-17
cmake --build agentc/build
```

Then re-run the script.
